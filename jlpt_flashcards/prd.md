# PRD — JLPT N4 일본어 암기장

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.6 (채점 규칙 테스트 후 조정, 개인용 명시) |
| 작성일 | 2026-10-24 |
| 대상 | JLPT N4(구 3급) 응시 초급 학습자 |
| 형태 | 모바일 우선 웹앱 (PWA) |
| 공개 범위 | 개인용. 앱과 데이터 모두 공개·배포하지 않음 |

---

## 1. 개요

### 1.1 배경
JLPT N4를 준비하는 초급 학습자는 N5보다 두 배 가까이 늘어난 단어와 활용이 복잡해진 문형을 외워야 하지만, 기존 학습 앱은 기능이 많고 화면이 복잡해 "그냥 빠르게 외우는" 경험을 방해한다. 종이 암기장(단어 카드)처럼 **앞면을 보고 뜻을 떠올리고, 뒤집어 확인하는** 단순한 흐름을 디지털로 옮긴다.

### 1.2 목적
- N4 필수 단어·문형을 **한자 표기 → 한국어 뜻** 순서로 반복 암기하게 한다.
- 틀린 문제를 자동으로 모아 **맞힐 때까지 재출제**해 취약 항목을 집중 복습하게 한다.

### 1.3 핵심 원칙
1. **단순함**: 한 화면에 한 문제. 버튼은 꼭 필요한 것만.
2. **한자 우선**: 한자 표기가 있는 단어는 반드시 한자로 먼저 보여준다.
3. **틀린 건 다시**: 오답은 자동 수집·재출제한다.

## 2. 사용자

| 구분 | 설명 |
|---|---|
| 주 사용자 | 히라가나·가타카나를 읽고 N5 기초(기본 단어·です/ます체)를 아는, N4 시험을 준비 중인 한국어 사용자 |
| 사용 상황 | 출퇴근·자투리 시간에 스마트폰으로 5~10분씩 학습 |
| 니즈 | 빠르게 넘기며 외우기, 모르는 것만 다시 보기 |

## 3. 학습 콘텐츠

### 3.1 범위
- **단어**: JLPT N4 필수 어휘 (N5를 제외한 N4 신규 어휘 약 600~700개)
  - 예: 経験, 準備, 説明, 届ける, 急ぐ, 珍しい, 丁寧, アルバイト
- **문형**: JLPT N4 필수 문형 (약 100~130개)
  - 조건: `〜たら`, `〜ば`, `〜と`, `〜なら`
  - 의무·허가·금지: `〜なければならない`, `〜てもかまわない`, `〜てはいけない`
  - 추측·전문: `〜そうだ`(양태/전문), `〜ようだ`, `〜らしい`, `〜かもしれない`, `〜はずだ`
  - 의지·결정: `〜(よ)うと思う`, `〜つもりだ`, `〜ことにする`, `〜ことになる`, `〜ようにする`
  - 상태·완료: `〜てしまう`, `〜ておく`, `〜てある`, `〜ところだ`
  - 수수: `〜てあげる`, `〜てくれる`, `〜てもらう`
  - 수동·사역·사역수동: `〜(ら)れる`, `〜(さ)せる`, `〜(さ)せられる`
  - 경어 기초: `お〜になる`, `お〜する`, `いらっしゃる`, `申す` 등
- **N5 복습**: N4 시험에도 N5 어휘·문형이 나오므로 N5 필수 어휘(약 700~800개)와 문형(약 80~100개)을 별도 범위로 제공한다.
  - 기본 출제는 N4이고, N5는 홈 화면에서 [N5 복습]을 고를 때만 출제한다.
  - 출제 표기 규칙·채점·오답 노트는 N4와 똑같이 적용한다.

### 3.2 출제 표기 규칙

| 단어 유형 | 문제에 표시되는 표기 | 예시 |
|---|---|---|
| 한자 표기가 있는 단어 | **한자(한자+오쿠리가나)** | 経験, 届ける, 珍しい |
| 히라가나로만 쓰는 단어 | 히라가나 | なかなか, ずいぶん, もし |
| 가타카나 외래어 | 가타카나 | アルバイト, パソコン, スーツ |
| 문형 | 문형 + 짧은 예문 | 〜てしまう / 財布を忘れてしまいました |

- 한자어 문제에서 읽기(히라가나)는 **기본적으로 숨김**, 버튼으로만 확인한다.
- 히라가나·가타카나 문제는 표기 자체가 읽기이므로 히라가나 버튼을 숨기고 [한국어 답] 버튼만 둔다.

### 3.3 예문 규칙
- N4 단어·문형은 **모두 예문 1문장**을 가진다. (N5 복습 항목은 선택)
- 수준: N4 범위의 단어·문형만 사용한 짧은 문장 (약 10~20자).
- **한자 우선 표기**: N4·N5 범위 한자로 쓸 수 있는 말은 한자로 쓴다. (예: `わすれて` ✕ → `忘れて` ○)
- 예문마다 히라가나 읽기와 한국어 해석을 함께 둔다.
- 예문은 Claude가 새로 작성한다. (3.5 참고)

| 대상 | 예문 예시 | 읽기 | 해석 |
|---|---|---|---|
| 経験 | 日本で働いた経験があります。 | にほんではたらいたけいけんがあります。 | 일본에서 일한 경험이 있습니다. |
| 届ける | 友達に荷物を届けました。 | ともだちににもつをとどけました。 | 친구에게 짐을 전해 주었습니다. |
| 〜てしまう | 財布を忘れてしまいました。 | さいふをわすれてしまいました。 | 지갑을 잊어버리고 말았습니다. |

- 표시 위치: 단어·문형 모두 예문(일본어)을 **문제 화면**에 함께 표시한다. 한국어 해석은 답을 알려 주므로 **채점 후 화면**에서만 보인다.
- 히라가나 버튼을 누르면 예문 읽기도 함께 보인다.

### 3.5 어휘·문형 목록 구축
JLPT 공식 어휘 목록은 공개되지 않으므로, **일반적으로 통용되는 JLPT N4(·N5) 수준 단어·문형을 Claude가 수집**해 데이터 파일로 만든다.

| 단계 | 내용 |
|---|---|
| 1. 목록 수집 | Claude가 시중 N4 단어장·학습 자료에서 일반적으로 N4로 분류되는 단어·문형 목록을 작성 (3.1 개수 기준) |
| 2. 급수 정리 | N5 단어는 N5 복습 범위로 분리, 중복 제거 |
| 3. 표기 정리 | 한자 표기 확정(한자 우선), 히라가나 전용·가타카나 단어 분류 |
| 4. 뜻·예문 작성 | Claude가 한국어 뜻(유의어 포함)과 N4 예문 1문장을 작성 |
| 5. 검수 | 사용자 본인이 확인하고 틀린 항목 수정 |

- 결과물: `data/n4-vocab.json`, `data/n4-pattern.json`, `data/n5-review.json` (3.4 구조)
- 급수 경계가 애매한 단어(자료마다 N4/N3가 다른 단어)도 **N4에 넣는다.**
- AI가 만든 데이터는 읽기·뜻이 틀릴 수 있다. 검수는 **사용자 본인이 학습하면서** 하고, 뜻이 부족하면 [내 답도 맞음]으로 보충한다.
- 데이터는 사용자 개인 학습용이며 공개·배포하지 않는다.

## 4. 핵심 기능

### 4.1 문제 화면 (메인)

```
┌──────────────────────────┐
│  12 / 50          오답 3   │  ← 진행도 / 오답 수
│                            │
│                            │
│          経 験              │  ← 문제 (크게)
│                            │
│        [ けいけん ]          │  ← 히라가나 버튼 누르면 표시
│                            │
│  ┌──────────────────────┐  │
│  │ 한국어 뜻 입력         │  │  ← 답 입력
│  └──────────────────────┘  │
│                            │
│  [ あ 히라가나 ] [ 한국어 답 ] │
│                            │
│        [   확인   ]          │
└──────────────────────────┘
```

| 요소 | 동작 |
|---|---|
| 문제 표기 | 화면 중앙에 크게 표시 |
| 입력창 | 한국어 뜻 입력. 엔터 = 확인 |
| **히라가나 버튼** | 읽기(히라가나)를 문제 아래에 표시. 한자어 문제에만 나옴 |
| **한국어 답 버튼** | 히라가나를 봐도 모를 때 누름. 정답을 바로 보여주고 **오답으로 처리** (모름 = 오답) |
| 확인 버튼 | 입력한 답을 채점 |

### 4.2 학습 흐름

```
문제 표시 (한자 우선)
   │
   ├─ 뜻을 앎 ──────────────→ 한국어 입력 → [확인]
   │                                  │
   ├─ 읽기가 궁금함 → [히라가나] → 읽기 표시 → 입력 or [한국어 답]
   │                                  │
   └─ 모름 ─────────→ [한국어 답] ──→ 오답 처리
                                      │
                       ┌──────────────┴──────────────┐
                    정답                            오답
                       │                              │
         "정답!" + 예문 해석 표시         정답·읽기·예문 표시
         → [다음](엔터)으로 넘어감          → 오답 노트에 추가
                       │                    → [다음](엔터)으로 넘어감
                       ▼                              ▼
                              다음 문제
```

### 4.3 채점 규칙 (유연한 채점)
뜻을 알고 있으면 표현이 조금 달라도 정답으로 인정한다. 아래 규칙을 순서대로 적용해 하나라도 통과하면 정답이다.

| 순서 | 규칙 | 예시 (정답 → 인정되는 입력) |
|---|---|---|
| 1 | **정규화 후 일치**: 공백, 문장부호(`.` `,` `~` `!` `?`), 괄호 안 보충 설명 제거 | `~해 버리다` → `해버리다` |
| 2 | **여러 뜻 중 하나**: `meanings`에 등록된 뜻·유의어 중 하나만 맞아도 정답 | `届ける`: 전하다 / 보내다 / 배달하다 → `보내다` |
| 3 | **어미 차이 허용**: 어미를 떼고 남은 말(어간)이 같으면 정답 (`-다` / `-요` / `-어요` / `-ㅂ니다` / `-하다` / `-해요` / `-한` / `-되다` / `-돼요` / `-이다` 등) | `준비하다` → `준비`, `준비해요` / `시작되다` → `시작` |
| 4 | **앞부분 포함**: 정답의 어간이 입력한 **단어의 맨 앞**에 있으면 정답 (2글자 이상) | `친절하다` → `친절한 것` (`불친절` ✕) |
| 5 | **짧게 쓴 답**: 정답이 입력으로 시작하고, 입력이 정답 길이의 절반 이상이면 정답 | `고장 나다` → `고장` (`늦잠 자다` → `자다` ✕) |
| 6 | **오타 1개 허용**: 자모(ㄱ, ㅏ 등) 1개 차이까지 허용. 정답이 자모 7개 이상이고 첫 글자가 같을 때만 | `설명하다` → `설멍하다`, `컴퓨터` → `컴퓨타` (`모으다`/`모이다` ✕, `간단하다`/`단단하다` ✕) |

- **부정어 막기**: 정답에 없는 부정어(`없` / `않` / `아니` / `못` / `안 되`)가 입력에 있으면 4·5번 규칙을 적용하지 않는다. (`필요하다` → `필요 없다` ✕, `경험` → `경험이 없다` ✕)

#### 채점 규칙 테스트 결과
샘플 N4 데이터(단어 37개 + 문형 9개)에 맞는 답 119개, 틀린 답 92개를 넣어 시험했다. 테스트 코드: `grading-test/`

| 구분 | 맞는 답을 정답 처리 | 틀린 답을 오답 처리 |
|---|---|---|
| 처음 규칙 (v0.5) | 116 / 119 | 79 / 92 (13개를 잘못 정답 처리) |
| **조정한 규칙 (현재)** | **117 / 119** | **92 / 92** |

- 처음 규칙의 문제와 조정 내용:
  - "정답이 입력을 담고 있으면 정답" → `늦잠 자다`에 `자다`가 정답 처리됨 → 5번 규칙으로 좁힘
  - "입력이 정답을 담고 있으면 정답" → `불친절`, `불필요`, `필요 없다`가 정답 처리됨 → 단어 맨 앞 조건 + 부정어 막기 추가
  - "한 글자 틀림 허용" → `모으다`↔`모이다`, `간단하다`↔`단단하다`, `정하다`↔`정리하다`, `늦어지다`↔`늘어지다`가 정답 처리됨 → 자모 단위, 자모 7개 이상, 첫 글자 일치 조건 추가
- 남은 한계: 불규칙 활용(`모이다` → `모여요`, `모르다` → `몰라요`)은 못 알아본다. 이런 답은 [내 답도 맞음]으로 보충한다.
- 테스트 답은 Claude가 만든 것이라 실제 학습에서 다른 사례가 나올 수 있다. 오판이 나오면 테스트에 추가하고 규칙을 다시 조정한다.

- 빈 입력으로 확인 시 채점하지 않고 입력창을 흔들어 알림.
- **히라가나 버튼을 눌렀어도 뜻을 맞히면 정답**으로 인정한다. (읽기 확인은 힌트일 뿐 감점 아님)
- **[내 답도 맞음]** 버튼: 입력해서 틀린 경우 오답 화면에 표시한다.
  - 누르면 정답으로 바꾸고 오답 노트에서 뺀다.
  - 그 입력을 해당 문제의 허용 답으로 기기에 저장해, 다음부터는 바로 정답 처리한다.
  - [한국어 답]으로 정답을 본 경우에는 이 버튼이 나오지 않는다.

### 4.4 정답/오답 처리

| 결과 | 화면 | 다음 동작 |
|---|---|---|
| 정답 | 초록색 체크 + "정답", 예문·해석 표시 | [다음] 버튼(엔터)을 눌러 이동. 자동으로 넘어가지 않음 (예문을 볼 시간을 줌) |
| 오답 | 빨간색 표시, 내 답(입력한 경우) / 정답 / 읽기 / 예문·해석 표시 | [다음] 버튼을 눌러 이동 (정답을 확실히 확인하게 함) |

- **모름과 오답은 같은 오답으로 처리한다.** 입력이 틀린 경우와 [한국어 답]을 누른 경우 모두 오답 수에 들어가고, 오답 노트에 똑같이 저장·재출제된다. 따로 집계하지 않는다.

### 4.5 오답 노트 & 재출제
- 오답 문제는 자동으로 **오답 노트**에 저장된다.
- 한 세트(라운드)가 끝나면 **이번 라운드 오답만 모아 바로 재출제**한다.
- 재출제 라운드에서도 틀린 문제는 다시 다음 재출제 라운드로 넘어간다. → **모두 맞힐 때까지 반복**.
- 재출제에서 맞힌 문제는 오답 노트에서 "해결됨"으로 처리되지만, 누적 오답 기록(틀린 횟수)은 유지한다.
- 홈 화면에서 **[오답만 풀기]**로 누적 오답 노트 전체를 언제든 다시 풀 수 있다.

### 4.6 세트 구성 (홈 화면)

```
┌──────────────────────────┐
│     JLPT N4 암기장          │
│                            │
│ [N4 단어] [N4 문형] [N5 복습] │  ← 출제 범위
│                            │
│  문제 수:  20 · 50 · 전체    │
│                            │
│  [     시작하기     ]        │
│  [  오답만 풀기 (23)  ]      │
│                            │
│  학습한 단어 312 / 680       │
└──────────────────────────┘
```

- 출제 범위: N4 단어 / N4 문형 / N5 복습 (하나 이상 선택, 여러 개 동시 선택 가능. 기본값: N4 단어)
  - N5 복습 = N5 단어 + N5 문형
  - 아무것도 고르지 않으면 [시작하기] 비활성화
- [오답만 풀기]는 범위와 상관없이 N4·N5 누적 오답 전체를 출제
- 문제 수: 20 / 50 / 전체
- 출제 순서: 아직 안 푼 문제 → 오답 이력 많은 문제 순으로 우선 출제하고, 같은 우선순위 안에서는 무작위.
- 학습 진행도: 선택한 범위 기준으로 "한 번 이상 맞힌 항목 수 / 전체" 한 줄만 표시.

### 4.7 라운드 결과 화면
- 정답 수 / 전체, 오답 목록(표기·읽기·뜻)만 간단히 표시.
- 버튼: **[오답 다시 풀기]** (오답이 있을 때 기본 버튼), [홈으로]

## 5. 디자인 가이드

### 5.1 원칙
- **종이 암기장 느낌**: 흰 배경 + 카드 한 장 + 굵은 문제 글씨.
- 화면당 요소 최소화. 장식·애니메이션·캐릭터·배지·랭킹 없음.

### 5.2 스타일

| 항목 | 값 |
|---|---|
| 배경 | 밝은 회백색 (#FAFAF8), 다크모드 시 #1C1C1E |
| 카드 | 흰색, 얇은 테두리 또는 아주 옅은 그림자 |
| 문제 글씨 | 일본어 폰트(Noto Sans JP/Noto Serif JP), 48~64px |
| 본문 글씨 | Pretendard 또는 시스템 폰트, 16px |
| 강조색 | 1개만 사용 (차분한 남색 계열) |
| 정답/오답색 | 초록 / 빨강 — 채점 결과에만 사용 |

### 5.3 사용성
- 한 손 조작: 주요 버튼은 화면 하단.
- 입력창 자동 포커스, 엔터로 확인 → 엔터로 다음 (키보드만으로 진행 가능).
- 모바일 360px 폭에서 가로 스크롤 없음.

## 7. 범위

### 7.1 v1 포함
- Claude가 수집·검수한 N4 단어·문형 데이터 내장 (항목마다 N4 예문 1문장)
- N5 복습용 단어·문형 데이터 내장, 홈 화면 출제 범위에서 선택
- 한자 우선 출제 / 히라가나·가타카나 단어 출제
- 유연한 한국어 입력 채점, [내 답도 맞음], 히라가나 버튼(읽기 표시), 한국어 답 버튼
- 모름·오답 동일 처리, 오답 자동 수집 및 라운드 후 재출제, 오답만 풀기
- 로컬 저장, 오프라인 사용

### 7.2 v1 제외 (번잡한 기능 배제)
- 회원가입·로그인·클라우드 동기화
- 랭킹, 배지, 연속 학습일, 포인트 등 게임화 요소
- 발음 재생 (TTS·음성 파일 모두)
- 객관식, 듣기 문제, 한국어→일본어 역방향 출제
- 사용자 단어 추가·편집
- 상세 통계·그래프
- 알림

## 9. 미결 사항

현재 남은 미결 사항 없음.

### 결정된 사항
| 항목 | 결정 |
|---|---|
| 채점 | 유연하게 채점 (4.3), 샘플 데이터로 시험해 규칙 조정 완료, [내 답도 맞음] 버튼 둠 |
| 예문 | N4 항목마다 N4 수준 예문 1문장, 한자 우선 표기 (3.3) |
| 문형 출제 | 문형 + 예문을 함께 표시 |
| 어휘 목록 | 일반적인 N4 수준 단어·문형을 Claude가 수집 (3.5), N4/N3 경계 단어도 N4에 포함 |
| 검수·공개 | 사용자 본인만 보고 검수, 공개·배포 안 함 |
| 발음 | 사용하지 않음. 히라가나 버튼은 읽기 표시만 |
| 모름 처리 | [한국어 답](모름)과 오답을 같은 오답으로 처리 |
